# Traces keep the Log Line text

Pairing never reads the words of a Log Line, but a Trace stores the full text of each one. Tests need Labels, and the amount in the line text is what ties a Log Line to its Hit when a script makes the Labels. A person then checks those Labels against the same text. We considered storing only the amount parsed from the line (this breaks across locales and line formats, and a wrong Label is hard to spot without the words) and storing no text, as Forever Combat Text does (every Trace is then labelled by hand, slowly and with less certainty). The cost is that a player's Trace holds their name and the names of the units they fought, so `/nsctr record` says so when it starts. The text is for Labels only: the recorder writes it, and the adapter does not pass it to Pairing.

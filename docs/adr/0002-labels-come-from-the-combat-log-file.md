# Labels come from the Blizzard combat log file

Supersedes 0001. The first recorded Trace showed that Forever sends each Log Line's text to addons as a `|K…|k` reference that only the chat frame can show, so the text holds no amount and cannot tie a Log Line to its Hit. Labels instead come from the file the game writes during `/combatlog` (`Logs/WoWCombatLog-*.txt`), which has millisecond times, real GUIDs, spell IDs, and amounts. The label script aligns that file with a Trace recorded at the same time, by matching the player's Log Lines to the player's lines in the file, then labels each Hit from the file. Only Traces made for tests need the file; a player's Trace needs no Labels. A Trace still keeps each Log Line's raw text, the `|K` reference, because a Trace keeps raw events, the cost is a few bytes a line, and any case where the game sends plain text will show in it.

## Amendment (2026-11-09): Swing Delays in the label script

In a group, amounts and GUIDs are secret, so several file events can fit one Hit. The script took the event nearest in time, but a swing's event comes one Swing Delay before its Hit, so a rival's later event won: in `warlock-bfd-group` the Labels gave the pet only 65 of about 131 swings whose Hit came at the pet's delay. The script now also checks the Hit's descriptor against the event's flags and a damaging Hit's school against the event's school, and among the events that still fit it prefers the ones on time: a spell's at the Hit's time, a swing's at one of its source's Swing Delays, learned from the Hits that only one swing fits. A row that only timing decides stays unsure, as another order of the same Hits can be on time too.

This makes the Labels less independent of Pairing for swings, since both now use timing. They stay a fair test because the script knows each swing's source from the file and learns each source's delays separately, which Pairing cannot do: Pairing sees only the player's and the pet's Log Lines, and a rival's Hit carries no source. A one-to-one matching of events to Hits per creature and fight was the next step if many rows stayed open; after these checks, 30 of 2,610 BFD rows remain where the choice changes a Log Line, so it is not built.

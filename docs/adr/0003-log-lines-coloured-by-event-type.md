# Log Lines are coloured by event type

A Log Line reaches addons with no words, so its colour is the only thing in it that can tell a Line Kind (a direct hit, a tick, a swing, a shot, a miss, a heal). Without a Line Kind, Spell Identity cannot tell a Shadow tick from a Shadow Bolt, and Pairing can give a spell's line to a melee Hit. So the Log Filter fix sets the filter to colour each line by its event type (`settings.lineColorPriority = 3`, with the addon's own colour for each event in `colors.eventColoring`), and the check asks for these colours, as Forever Combat Text does. This changes the colours of the player's Combat Log tab. It also ends line colours by source, which Pairing used to tell other players' lines from the player's, so Pairing now depends on a Done By of only "Me" and "My pet", which the fix already sets.
